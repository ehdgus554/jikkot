# 콘텐츠 확정과 기술 구현을 구분합니다

기존 MVP 커밋 `aca2be21aabc03d952128ccb1bebb228613d91d5`의 5개 부위, 질문, MV001~MV030 동작과 routes를 사용합니다. `app/jikkot-data.ts`의 원본 콘텐츠는 변경하지 않았습니다.

- 문진 순서는 자세 → 부위 → 생활 습관 → 최근 상태입니다. RA99/HB99는 원본 자료에만 남고 화면·서버 선택지에서 제외됩니다. 2개 제한은 없습니다.
- 자세는 seated=앉기, standing=앉기+서기, lying=앉기+서기+눕기의 **누적 허용**입니다. ‘누워서 할 수 있음’이 누워서만 수행한다는 뜻은 아닙니다.
- `lib/service/recommendation.ts`가 기존 최근 상태 태그의 첫 매칭 route를 선택합니다. routes 배열 순서가 임시 패턴 우선순위이고, 각 슬롯 안에서는 기존 습관 매칭 우선·원래 후보 배열 순서를 유지합니다. relax→move→control 후보 순서의 첫 적합 동작 하나를 보여줍니다. 새로 검증한 패턴 점수 모델은 없습니다. 선택한 route에 없는 동작으로 fallback하지 않습니다.
- `npm run content:check`는 현재 6,975개 자세/부위/최근 상태/습관 대표 조합을 검사합니다. 최종 콘텐츠 교체 시 다중 선택 조합과 추가 연결도 별도 검수해야 합니다.
- 생활 습관에 따른 조건부 최근 상태 연결표는 없습니다. `ContentExtensions.recentQuestions`가 교체 지점이며, 현재 부위별 MVP 질문을 사용합니다.
- `ContentExtensions.related`는 같은 패턴에 연결된 다른 부위 추천입니다. `changes`는 동작별 악화 질문·다음 동작 연결입니다. 운영 설정은 비어 있습니다. 회원의 ‘비슷하다/더 불편하다’는 ‘추가 추천 없음 → 완료하기’로 처리합니다. 임의의 의학적 질문·연결을 만들지 않았습니다.
- 단위 테스트와 Functions API factory의 테스트 전용 fixture로 조건부 질문·다른 부위 추천·변화 답변 저장을 검증합니다. fixture는 운영 번들에 포함하지 않습니다.
- `components/routine-media.tsx`는 native 이미지로 GIF/애니메이션 WebP를 재생할 수 있습니다. 현재 실제 파일은 기존 WebP/SVG 이미지이며 GIF를 제공했다고 주장하지 않습니다. 정적 자산을 그대로 제공하여 IMAGES binding 의존성도 제거했습니다.
- 스트레칭·쇼핑 feature flag는 기본 false이며 준비 중 안내만 있습니다. 결제·평생회원 판매·관리자 화면은 없습니다.

출시 전 확정할 것: 질문/패턴/동작 검수, 조건부 질문표, 관련 부위 재추천표, 악화 질문표, 실제 GIF, 개인정보 동의 문안, 운영 데이터 보관기간·삭제 절차. 개발용 동의 버전은 `draft-v1`입니다. 회원·비회원의 운영 데이터와 회원 개인 기록은 별도 컬렉션입니다.
