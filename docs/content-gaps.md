# 현재 추천 콘텐츠 범위

2026-10-12 사용자 요청과 [다섯 부위 명세](five-areas-request.md)를 기준으로 추천 콘텐츠를 `jikkot11-v2-fiveareas`으로 교체했습니다. 원본 ZIP의 PNG 11장은 `public/assets/routines/routine-*.png`에 변환 없이 저장했습니다. 기존 WebP/SVG는 과거 기록의 자산 경로를 보존하기 위해 삭제하지 않았습니다.

- 추천 질문은 불편 부위 하나 → 평소 습관 복수 → 최근 행동 복수의 세 개입니다. 자세/추가 위치/강도/후보 선택 질문을 넣지 않습니다. 현재 안내 동작은 앉은 버전입니다. `mode` 필드는 기존 기록·목록 맥락과 API 호환을 위해 보존하며 분기를 결정하지 않습니다.
- 다섯 부위(머리·목·어깨·등·허리), 18개 습관 ID, 15개 최근 행동 ID는 승인 프로필에 맞춰 노출합니다. 습관의 H_UNKNOWN, 최근 행동의 R_NONE/R_UNKNOWN은 다른 항목과 배타적으로 처리합니다. 빈 배열은 추가 질문 없이 해당 특별 옵션으로 정규화합니다.
- 결정 트리는 제공된 순서와 조건 그대로 첫 최종 분기에서 하나를 반환합니다. 전 단계 제외 조건을 메타데이터에 기록합니다. 점수, 무작위, 동점 처리, MVP fallback은 없습니다.
- 추천 이유에는 실제 최종 분기를 결정한 입력만 넣습니다. 기본 분기는 부위만 설명합니다. 내부 분기/패턴 ID는 화면에서 표시하지 않습니다.
- 승인 동작은 jikkot11-r01~r11이고 표시 번호 1~11과 분리합니다. 새 저장에는 jikkot11-v2-fiveareas/새 ID/실제 안내 단계/선택 스냅샷을 기록합니다. 과거 MV 스냅샷은 그대로 표시하며 새 번호로 치환하지 않습니다.
- 비슷/더 불편의 다음 추천도 같은 부위의 승인 매핑과 결정 트리 콘텐츠 순서 안에서 현재 동작을 제외합니다. 추가 질문을 만들지 않습니다. 허리는 동작 1만 승인되어 다음 동작이 없습니다. 과거 버전의 진행 중 추천에는 새 동작을 자동 연결하지 않습니다.
- 단계는 문서의 두 단계/세 단계 그대로 표시합니다. 이미지 안의 원문 안내를 사용하며, 새 수행 시간·횟수·타이머 기본값을 만들지 않았습니다. GIF/영상은 이번 승인 콘텐츠의 요구사항이 아닙니다.
- 로그인·동의·비회원 KST 하루 한도·회원 기록·로그아웃은 기존 Spark API 흐름을 사용합니다. 스트레칭/쇼핑은 기존 준비 상태를 유지합니다.

동의 문안과 운영 보관 정책은 여전히 개발 초안(`draft-v1`)이며 추천 알고리즘 교체 작업에서 변경하지 않았습니다. 추천 변경은 기존 Cloudflare 운영 Git 배포 경로로 반영하며, 실제 Firebase 계정 설정과 규칙·인덱스는 변경하지 않습니다.
